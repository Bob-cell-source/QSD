# LoCoRec 后续研究记录：先识别机制，再建立贡献

检索日期：2026-09-10。结论依据公开论文、作者代码和本地实验；未检索到同名方法不是新颖性证明。此文档是研究记录，不是已完成的新方法或投稿承诺。

## 当前证据改变了什么

1. 原四模型、三种子的结果支持单表 Soft 比单表 Hard 小幅提升，但 Full 仍更强；详见 VALIDATION_OFFICE.md。
2. Full 最佳 checkpoint 均来自 gate 解冻之前。seed 2026 的固定先验重训复制了前期曲线及最佳测试 NDCG@10=0.067272，因此暂时没有证据把这部分收益归因于可学习 gate 修正。
3. 公共投影偏置使 Full 初始物品两两 cosine 达到约 0.776，单表 Soft 为 0.021。去掉偏置后 Full 降到 0.043。相同的未缩放点积公式并不等于相同的有效温度。统一缩放重训因此是必要对照，不能把原四模型排名直接解释成模块必要性。
4. SID 行置换实验保持了完整 tuple 的多重集合及各层 code occupancy，训练 seed 与原 Hard 配对；用于检验内容与 sharing topology 的对应关系。置换实验仅采用一个固定置换 seed=1701，不能代表所有随机拓扑。

## 最接近工作及不能重复声称的贡献

| 已核查的一手来源 | 实质重叠 | 对当前路线的影响 |
|---|---|---|
| [Better Generalization with Semantic IDs](https://arxiv.org/abs/2306.08121) | 将 SID 引入判别式 ranking，利用 token/子序列组成表示 | “固定 SID 用于判别式推荐”和“SID 带来共享”本身不是新贡献 |
| [AKT-Rec](https://arxiv.org/html/2605.23310v1) | cluster 与 individual 表示、activity-aware gate、非对称头尾迁移 | 共享/私有加频次 gate 与其非常接近，不能只用 CTR vs sequential 区别回避机制比较 |
| [H2Rec](https://arxiv.org/abs/2512.10388)，[作者实现](https://github.com/ziwliu8/H2Rec) | SID/HID 双分支、多粒度融合与对齐 | 必须纳入最接近的判别式序列推荐比较，不宜再以双分支融合为主创新 |
| [CapsID](https://arxiv.org/abs/2605.05096) | soft routing 与可变长度 SID | “soft”或“停止/分辨率”不天然构成新颖性 |
| [DRQ](https://arxiv.org/html/2606.01844v1) | expected overlap、有效容量与边界混淆诊断，解耦量化 | 仅补一个 overlap 指标或把熵称为共享成本不足以形成新原则 |
| [QuaSID](https://arxiv.org/html/2603.00632v1) | 区分有效冲突与良性重合，并做严重度相关的排斥 | 不能笼统声称首次识别有害/有益碰撞 |
| [AdaSID](https://arxiv.org/abs/2604.23522) | 按语义兼容性保留重合，并依负载和训练进度调节压力 | “可靠邻居保留、不可靠邻居抑制”已有非常接近工作 |
| [BLOGER](https://arxiv.org/abs/2510.21242) | tokenizer/recommender 双层优化及 gradient surgery | 不能把增加 meta loss 或梯度冲突修正当成全新的原理 |
| [SEvo](https://proceedings.neurips.cc/paper_files/paper/2024/file/938ac7bb9a997b60b6be0348c486aaef-Paper-Conference.pdf) | 在 embedding 更新中引入图结构，无需前向 GNN，包含 AdamW 集成和理论分析 | “SID 只在训练时共享梯度”作为大方向已不新。当前 transfer.py 只能算机制探针，不是 SEvo 复现 |
| [STAIR](https://arxiv.org/html/2412.11729v1) | 通过 multimodal kNN 对 descent directions 做 backward convolution | 将 SEvo 的图换成文本邻居也不是足够的差异 |
| [Understanding Semantic IDs: From Item Representation to Item Selection](https://arxiv.org/html/2607.24995v1) | 系统研究细邻域丢失、assignment 不稳定与生成过滤问题 | 可支持更精确的问题定义，但“SID 不保留细局部结构”已有公开诊断；其 ISD 是生成解码干预，与当前判别式模型不同 |
| [DREAM](https://arxiv.org/abs/2606.06947) | 利用协同证据逐步修正早期 SID assignment | 不能仅以固定 tokenizer 后再校准 assignment 区别整个相关工作集合 |

上述研究范围不同，不表示它们逐项等价于 LoCoRec；但也不能用应用场景不同来替代实质算法差异。原 related work 中把相关方法一概概括为“主要修改 tokenizer”过于宽泛，特别是 AKT-Rec/H2Rec 的 downstream 融合部分应明确讨论。

## 已实现但降级为对照的训练算子

对 Hard SID 第 l 层分组定义组均值投影 Pi_l，并令 C=(1/L) sum_l Pi_l。只对 item embedding 的梯度应用：

`G' = [I + eta (C - diag(C))] G`, 固定 eta=0.5。

前向仍是 ID-only，没有 SID embedding、attention 或 gate；占用归一化避免大组以总和而非均值传播，去掉对角项用于隔离自更新与跨物品传播。

每个 Pi_l 是对称幂等矩阵，因此 C 为半正定收缩算子。K=I+eta(C-diag(C)) 的对角线为 1，eta∈[0,1] 时谱位于 [1-eta,1+eta]。实现已通过小矩阵数值等价、谱界、singleton 无跨物品更新及只改变反向的测试。

这些性质本身来自标准投影/矩阵分析。实际实现是在 AdamW 与 clipping **之前**修改梯度，不能由 K 的半正定性推出 AdamW 每步下降，更不能声称官方 SEvo 已被复现。因为相关工作重叠明显，除非发现额外、明确且可验证的失败机制，不能把它作为投稿主创新。

## 值得继续检验的具体问题，尚未定为新方法

### 1. 共享拓扑的迁移作用与自更新尺度能否分开识别？

固定 assignment 的线性表示 V=A E+P，在普通、同学习率且无正则的 SGD 下，直接对 E/P 更新诱导 V 的更新 `(A A^T + I) G`。这只是基础代数恒等式，不是新定理。它提示需要分开控制非对角跨物品迁移、对角学习率、以及初始化分数尺度；目前 gate/单表实验尚未完成这种因果归因。

若“只改变对角/温度”的控制已复现主要收益，就应缩减 LoCoRec 的机制主张；如果匹配这些因素后 SID 的非对角结构仍明显有效，才有理由开发更精确的共享校准。必须比较 SEvo/STAIR 风格算子，不能只比较无共享 ID。

### 2. 语义相近是否等于可共享推荐监督？

可考虑以**不同训练用户上的推荐迁移效果**作为局部一致性的可测目标，而不是只用 token overlap、频次或最终 embedding 相似度循环定义可靠性。探索时必须排除物品自己的直接收益，并使用用户分离的训练子集估计和检验迁移，否则容易把自拟合称作迁移。

这只是目标层面的候选问题。梯度一致性、meta-learning、图结构学习均有大量先例；还没有证据证明一个具体的、足够不同的优化目标成立。若统计量跨训练用户不稳定，或不能预测 held-out 迁移，应停止该路线，不能靠添加 gate 把问题掩盖。

## 达到投稿候选状态所需证据

- 形成一个明确、区别于上述最近方法的算法变化，能够直接解释为什么该变化解决已测得的问题。
- 在控制 score scale、初始化、参数量差异解释和训练协议后，优于强 Hard/简单 Soft，多个种子有一致趋势。
- 补充第二个 Amazon 域及非 Amazon 数据；不凭 Office 单 seed 宣称适合投稿。
- 最近邻方法与同骨干机制对照，报告均值/标准差、分组样本数及负向结果。
- 明确冻结文本编码器、文本字段、SID 构建、切分和调参协议；测试集不能继续参与候选筛选。

目前这些条件尚未满足。正在进行的是验证与路线筛除，不能将其包装成已有足够创新性的新论文。
